 在 Gemini CLI 中查看之前的聊天記錄，主要有以下幾種方式： 
 ### 1. 使用命令列參數 (CLI Flags)\n在終端機啟動 Gemini CLI 前，您可以使用以下指令：
 查看所有對話列表：執行 gemini--list-sessions。這會列出目前專案中所有自動儲存的工作階段及其編號。
- 恢復最近的對話：執行 gemini --resume (或 -r)。
- 恢復特定編號或 ID 的對話：執行 gemini --resume <編號> 或 gemini --resume <Session_ID>。

### 2. 在互動介面中使用指令 (Slash Commands)\n如果您已經進入了聊天介面，可以使用：\n- /resume：開啟工作階段瀏覽器 (Session Browser)。這是一個互動介面，您可以捲動瀏覽、搜尋內容、預覽對話時間與訊息數量，並選擇要恢復的記錄。
- /chat list：列出目前專案中手動儲存（帶有標籤）的聊天狀態。
- /rewind (或連按兩次 Esc)：向後回溯，查看當前對話中之前的互動、檔案變更，並可選擇退回至該狀態。

### 3. 本機儲存位置\n所有的聊天記錄會自動以 JSON 格式儲存在本機目錄中，您可以直接前往查看原始檔案：
- Windows: C:\\Users\\<您的使用者名稱>\\.gemini\\tmp\\<專案雜湊值>\\chats\\
- Linux macOS: ~/.gemini/tmp/<專案雜湊值>/chats/
*註：對話記錄是與專案目錄掛鉤的，切換到不同的專案資料夾會看到不同的歷史記錄。*
